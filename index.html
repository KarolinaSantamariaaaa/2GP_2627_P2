  1. Crear la carpeta del codigo en nuestro disco duro, trabajamos en local offline
  2. Abrir Visual Studio Code, arrastrar la carpeta al explorador o open folder
  3. Crear New File: index.html
  4. Editar el archivo, agregar texto, imgs, etc...
  5. Abrir el navegador y acceder a nuestro perfil de Github
  6. Crear un repositorio, por ejemplol la P1
  7. Add files y upload files
  8. Una vez aparezca el archivo index.html en el directorio de nuestro repositorio, hay que ir a settings y buscar Pages, cambiamos none a main, y apretamos save
  9. Esperamos un poco y nos aparecerá nuestra URL del repositorio publicado en formato web Page
